Why

Pathology has a lot of images and few expert labels. Self-supervised learning reads the images alone and builds features; the labels are only needed at the end, and then only a few. I wanted to see how far that goes at a realistic resolution on my own hardware: PathMNIST at 224 px, nine tissue classes, a small ViT on a 24 GB Mac.

The method: LeJEPA

I started with I-JEPA, which predicts hidden patches in latent space and needs a slowly moving teacher network (an EMA copy) to keep the features from collapsing. It worked, but the teacher is a moving target, and I wanted a method with a fixed objective. LeJEPA has one, with two terms:

  • Agreement: eight views of each image (two whole, six local windows) are pulled toward their common centre in embedding space.
  • SIGReg: the batch of embeddings must look like an isotropic Gaussian. It is checked along 1,024 random directions per step with a classic normality test (Epps–Pulley), which compares each projection's characteristic function with the bell curve's. A collapsed embedding fails it badly, so collapse is ruled out by the objective itself.

No teacher, no stop-gradient, no predictor; one weight balances the two terms. The views are cut at native resolution, never resized, so a cell is always the same number of pixels: at one fixed magnification, size is information. (The animation on the front page is SIGReg at work.)

All labels: features that travel

Frozen encoder, mean-pooled features, a linear classifier trained on the 90,000 labelled training images. The test images come from a different clinical centre than the training images, so they also measure how well the features travel:

One percent of the labels

The real question for pathology: with labels for only 1% of the images (901, stratified by class), do the self-supervised features beat a network trained from scratch on those same labels? The frozen features win by 13 points over the best from-scratch network, far more than the 1–3 points the three label subsets differ by. With all labels the same probe reaches 95.9%, so 99% fewer labels cost about 4 points. The baselines use one fixed recipe, not tuned; tuning might add a few points to them, not thirteen.

Lesson A random-init baseline is essential: a linear probe on random ViT features already reaches 68% with all labels, so an absolute number on its own says little about what pretraining did. And the clinical-centre shift on the test split showed a difference between the methods that the validation split hid.

Where it started: I-JEPA

The first runs also settled the engineering on a 24 GB Mac: the 224 px split ships as a compressed .npz that pulls ~13.5 GB into RAM, so each split is decompressed once to an .npy and memory-mapped, which brings data RAM to roughly zero and lets the data-loader workers share pages.
