LeJEPA on pathology images

Self-supervised pretraining on 90,000 tissue images, no labels and no teacher network. With labels for only 1% of them, a linear classifier on the learned features reaches 91.6%, against 78.6% for a ResNet-18 trained from scratch on the same labels.

How I work

Habits from scientific computing

01

Measure, don't assume

Build the diagnostic and run it. In ball-in-cup, a probe that was 12× more accurate changed nothing, and only an n=30 closed-loop test showed that.

02

Explicit over implicit

Typed state, pure transitions, bounded retries. If a system does something, I want to be able to point at the line that made it happen.

03

Ablate your fixes

When a stack of changes finally works, find out which ones carry the result. Keeping only those is how the next person understands the system.
